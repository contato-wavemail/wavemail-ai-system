# Como usar o WaveMail AI System

Este sistema foi criado para transformar Claude ou ChatGPT em um especialista em e-mail marketing, CRM, retenção e automações para e-commerce.

## Passo 1

Abra o arquivo:

skills/email-marketing.md

## Passo 2

Baixe ou copie o conteúdo desse arquivo.

## Passo 3

Abra o Claude ou ChatGPT.

## Passo 4

Envie o arquivo `email-marketing.md` na conversa.

## Passo 5

Cole o prompt principal disponível em:

prompts/prompt-principal.txt

## Passo 6

Comece a pedir tarefas como:

- Crie uma automação de carrinho abandonado
- Crie uma sequência de boas-vindas
- Analise minha campanha
- Melhore esta copy
- Crie um calendário de campanhas
- Analise meu pop-up
- Estruture uma estratégia de retenção
